- **Library**: @shadergradient/react with Three.js ecosystem

### 2. Dotted Grid Overlay ✅
- **Pattern**: radial-gradient with circular dots
- **Styling**: 
  - Dot color: rgba(34, 197, 94, 0.4) (green)
  - Size: 1px dots
  - Spacing: 24px × 24px grid
  - Opacity: 30%
- **Position**: Fixed overlay above shader, below widgets

### 3. Widget Selection States ✅
- **Selection Trigger**: onClick handler for each widget
- **Visual Feedback**:
  - Border changes: 1px gray → 2px green-500
  - "Selected" badge appears (green bg, white text, top-left)
- **State Management**: selectedWidget state variable
- **Deselection**: Click canvas background (canvas-background class)

### 4. Smart Canvas Control ✅
- **Panning Logic**: 
  ```typescript
  panning={{ 
    disabled: selectedWidget !== null,
    // ... other settings
  }}
  ```
- **Dragging Logic**:
  ```typescript
  isDraggable={selectedWidget === null}
  ```
- **Benefits**:
  - Prevents accidental canvas movement when editing widget
  - Enables precise widget resizing without canvas drift
  - Clear separation between canvas and widget interactions

### 5. Performance Optimization ✅
- **useCallback Implementation**:
  - `handleSearch` - memoized search handler
  - `handleDelete` - memoized delete with widget ID parameter
  - `handleWidgetClick` - memoized selection handler
  - `handleCanvasClick` - memoized deselection handler
- **useMemo Implementation**:
  - `memoizedWidgets` - prevents widget object recreation
  - `memoizedActiveWidgets` - filters only when activeWidgets changes
- **Performance Impact**: Eliminates unnecessary re-renders

### Selection State Logic
```typescript
// Selection handler
const handleWidgetClick = useCallback((widgetId: string) => {
  setSelectedWidget(widgetId);
}, []);

// Deselection handler
const handleCanvasClick = useCallback((e: React.MouseEvent) => {
  if ((e.target as HTMLElement).classList.contains('canvas-background')) {
    setSelectedWidget(null);
  }
}, []);

// Widget border conditional
className={`... ${
  selectedWidget === widget.id 
    ? 'border-2 border-green-500 shadow-lg shadow-green-200/50' 
    : 'border border-gray-200'
}`}
```
