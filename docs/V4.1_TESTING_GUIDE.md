## 🧪 Test Scenarios

### 1. RAG Memory System

**Test:**
1. Search for "housing in Bloomsbury London"
2. Wait for 5 widgets to generate
3. Ask follow-up: "What about crime rates specifically?"
4. Ask another follow-up: "Are there good schools nearby?"

**Expected Results:**
- ✅ Second query doesn't duplicate existing "Crime Rates" widget
- ✅ Third query uses context from previous questions
- ✅ API logs show "Conversation history length: 4" or 6
- ✅ No duplicate widget titles

**How to Verify:**
- Check browser console: "Conversation history length: X"
- Check server logs: "Processing housing search query" with history
- Widgets should have unique titles (e.g., "Schools 1", "Schools 2")

### 5. Smaller Widget Sizing & Bento Grid

**Test:**
1. Search for any location
2. Observe generated widgets

**Expected Results:**
- ✅ Widgets are smaller (2x2 grid units, not 3x2)
- ✅ Text is more readable (not tiny)
- ✅ 3-4 widgets fit per row (bento-style)
- ✅ Not all widgets in single column

**How to Verify:**
- Zoom out canvas (Ctrl+Scroll)
- Count widgets per row (should be 3-4)
- Check text size (should be legible)
- Compare to v4.0 (previously centered single column)

**Before (v4.0):**
```
[ Widget 1 ] [ Widget 2 ] [ Widget 3 ] [ Widget 4 ] [ Widget 5 ]
     (all centered in single row or column)
```

**After (v4.1):**
```
[ Widget 1 ] [ Widget 2 ] [ Widget 3 ]
[ Widget 4 ] [ Widget 5 ]
     (bento grid, 3 per row)
```
