## 🐛 Issues Fixed

### 1. **API Error 400 - Conversation History** ⚠️ CRITICAL

**Problem:**
```
Error: 400 {"error":{"message":"After the (optional) system message(s), 
user or tool message(s) should alternate with assistant message(s)."}}
```

**Root Cause:**
- Conversation history included consecutive messages from the same role
- Success messages (✅) and welcome messages (👋) were sent to API
- Perplexity API requires strict alternation: user → assistant → user → assistant

**Fix:**
```typescript
// ChatWindow.tsx - Filter and ensure alternating messages
const filteredMessages = messages.slice(-6).filter(msg => {
  return !msg.content.includes('✅') && !msg.content.includes('👋');
});

const conversationHistory: Array<{role: 'user' | 'assistant', content: string}> = [];
let lastRole: 'user' | 'assistant' | null = null;

for (const msg of filteredMessages) {
  const role = msg.role === 'user' ? 'user' as const : 'assistant' as const;
  if (role !== lastRole) {
    conversationHistory.push({ role, content: msg.content });
    lastRole = role;
  }
}
```

### 2. **Thinking Message Stuck After Initial Search** 💭

**Problem:**
- Initial search from homepage shows thinking animation
- After 5 widgets load, thinking animation never stops
- Chat appears frozen

**Root Cause:**
- `isLoading` state in ChatWindow wasn't synced with GridPage's `isSearching`
- No success message added after initial search completes

**Fix:**
```typescript
// ChatWindow.tsx - Added props and effect
interface ChatWindowProps {
  isSearching?: boolean; // External loading state from GridPage
}

// Effect to handle external search completion
useEffect(() => {
  if (initialQuery && !initialSearchCompleted && !externalSearching && existingWidgets.length > 0) {
    setInitialSearchCompleted(true);
    setIsLoading(false);
    
    const successMessage: Message = {
      id: Date.now().toString(),
      role: 'assistant',
      content: `✅ I've created ${existingWidgets.length} widgets based on my research!`,
      timestamp: new Date(),
    };
    setMessages(prev => [...prev, successMessage]);
  }
}, [initialQuery, initialSearchCompleted, externalSearching, existingWidgets.length]);

// GridPage.tsx - Pass isSearching prop
<ChatWindow 
  isSearching={isSearching}
  // ... other props
/>
```

### 3. **Missing 'a' Letters in Headers** 🔤

**Problem:**
- Widget headers show "Current **sfety d crime**" instead of "Current **safety and crime**"
- Random letter dropping throughout content
- Markdown asterisks (**) still visible in output

**Root Cause:**
- System prompt wasn't explicit enough about complete words
- Perplexity was still using asterisks for bold formatting
- Prompt didn't emphasize proper markdown syntax

**Fix:**
```env
# .env.local - Much more explicit system prompt
PERPLEXITY_SYSTEM_PROMPT="You are a real estate research assistant. CRITICAL INSTRUCTIONS: 1) NEVER use asterisks (**) for bold text - the frontend handles formatting. 2) Use ### for headers (e.g., ### Safety and Crime). 3) Write ALL words completely - never abbreviate or drop letters (write 'safety and' not 'sfety d'). 4) Add citations [1][2] after facts. 5) Use bullet points with - for lists. 6) Keep responses 400-600 words for detailed information. 7) Be specific and informative."

PERPLEXITY_PROMPT_SUFFIX=" IMPORTANT: Write in plain text with markdown syntax. Use ### for headers (NOT **). Write complete words (safety, area, crime) without dropping letters. Include citations [1][2]. Use - for bullet points. Provide 400-600 words of detailed, useful information."
```

### 4. **Widget Content Too Concise** 📏

**Problem:**
- Widgets show very little content before opening
- User has to expand every widget to see details
- Poor user experience - can't scan information quickly

**Root Cause:**
- Widget sizes too small (1x2, 2x2 grid units)
- System prompt requested 300-400 words (too short)
- Height calculation limited content visibility

**Fix:**
```typescript
// route.ts - Larger widget sizes
function calculateWidgetSize(content: string): { w: number; h: number } {
  const length = content.length;
  
  if (length < 400) return { w: 2, h: 3 }; // Small content
  if (length < 800) return { w: 2, h: 4 }; // Medium content - taller
  if (length < 1200) return { w: 3, h: 4 }; // Large content - wider and taller
  return { w: 3, h: 5 }; // Very large content - maximum size
}

// GridPage.tsx - Use API sizes directly
const height = widgetData.size.h * 2; // Convert to grid units (not capped)
const width = widgetData.size.w * 2;   // Convert to grid units (not capped)

lg.push({
  w: width,  // 4-6 grid units
  h: height, // 6-10 grid units
  minW: 4,
  minH: 6,
});

// .env.local - Request more detailed content
"Keep responses 400-600 words for detailed information"
```

### 5. **Citations Not Hyperlinked** 🔗

**Problem:**
- Citations [1][2] in widget content not clickable
- Footer shows clickable badges but no actual URLs
- All citation URLs were placeholder `#citation-1`

**Root Cause:**
- Not extracting actual URLs from Perplexity API response
- Citation extraction only looked for [1][2] pattern, not URLs
- API response has citations but we weren't accessing them

**Fix:**
```typescript
// route.ts - Extract citations from API response
interface QueryResult {
  content: string;
  citations: Array<{ number: number; url: string; title: string }>;
}

async function executeSingleQuery(prompt: string, conversationHistory: ConversationMessage[] = []): Promise<QueryResult> {
  const completion = await client.chat.completions.create({
    model: "sonar-pro",
    messages,
  });
  
  const citations: Array<{ number: number; url: string; title: string }> = [];
  
  // Check if response has citations field
  if ((completion as any).citations && Array.isArray((completion as any).citations)) {
    const apiCitations = (completion as any).citations;
    apiCitations.forEach((cite: string, index: number) => {
      citations.push({
        number: index + 1,
        url: cite,
        title: `Source ${index + 1}`
      });
    });
  } else {
    // Fallback: extract URLs from content using regex
    const urlPattern = /https?:\/\/[^\s\)]+/g;
    const urls = contentString.match(urlPattern) || [];
    urls.slice(0, 10).forEach((url, index) => {
      citations.push({
        number: index + 1,
        url: url,
        title: `Source ${index + 1}`
      });
    });
  }
  
  return { content: contentString, citations };
}
```
