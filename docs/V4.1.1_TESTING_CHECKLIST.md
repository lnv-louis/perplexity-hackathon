## Network Tab Checks

Open DevTools (F12) → Network → Filter: Fetch/XHR

**Look for:**
- `POST /api/search`
- Status: 200 (not 400 or 500)
- Response time: 15-20 seconds (initial), 5-10 seconds (follow-up)

**Click on request → Preview tab:**
```json
{
  "widget_count": 5,
  "widgets": [
    {
      "id": "safety",

      ],
      "size": {"w": 2, "h": 4}  // ← Larger sizes
    }
  ]
```
